【Travel Planner 手機 PWA 安裝與放到桌面說明】

若您想要在手機（iPhone 與 Android）上將行程放到桌面當作獨立 App 使用，且在無網路時也能離線開啟：

■ 方法一：免架站 3 秒取得永久 HTTPS 網址（最推薦出國隨身使用）
1. 打開瀏覽器至 Netlify Drop (https://app.netlify.com/drop)
2. 將此 ZIP 解壓縮後的整個資料夾，直接拖曳進該網頁中（免註冊登入即可使用）
3. 系統會在數秒內給您一組專屬的免費 HTTPS 網址（例如：https://my-trip.netlify.app）
4. 手機安裝至桌面步驟：
   - 🍎 iPhone (iOS)：
     用 Safari 開啟該網址 ➜ 點選螢幕下方「分享按鈕 ⎋」➜ 選擇「加入主畫面 ⊞」➜ 點右上角「新增」。
     完成後 iPhone 桌面會出現 Travel Planner 圖示，點開即是全螢幕獨立 App，離線亦可正常使用！
   - 🤖 Android：
     用 Chrome 開啟該網址 ➜ 點選畫面跳出的「安裝應用程式」或右上角「︙」➜ 選擇「新增至主螢幕」。
     完成後 Android 桌面會出現專屬圖示。

■ 方法二：單一離線 HTML 檔案
- 此資料夾中的 index.html 為完全單檔自給自足的離線版本，您也可以直接用 AirDrop、LINE、Email 傳送給同行朋友，手機瀏覽器點開即可離線檢視！
